# Industrial Gateway Demo
Modbus Gateway / IEC104 Gateway + Qt Upper Computer

## Directory Structure
- `basic_demo`：基础示例（socket、serial、thread、log）
- `modbus_gateway`：Modbus RTU <-> TCP 网关
- `iec104_gateway`：IEC 60870-5-104 规约网关
- `qt_upper_computer`：Qt上位机，数据可视化、下发指令
- `docs`：规约文档、接口说明
- `scripts`：编译、部署脚本
